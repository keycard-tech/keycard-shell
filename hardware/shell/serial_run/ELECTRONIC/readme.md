# Main board version

Keycard Shell units from the first production (December 2025) use main board
**KCP-2282-601 PCB V3.7**, printed on the back of the board.

The V3.7 manufacturing files (Gerbers, pick-and-place, PCB and assembly PDFs)
are in the pilot run folder:
[`pilot_run/electronics_and_bom/gerber/KCP-2282-60x-V3.7.8.zip`](../../pilot_run/electronics_and_bom/gerber/KCP-2282-60x-V3.7.8.zip)

This folder holds **V3.8** (`KCP-2282-60x-V3.8.9`), the next revision. It has not been produced yet.
The only change from V3.7: longer pads for the USB-C connector (J8).
All other components and their positions are the same.

BOM: V3.9 replaces D6 `BZX585-C30` (30 V) with `BZX585-C3V0` (3 V).
Units may carry either part.
